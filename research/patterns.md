## CATEGORY 1 — DRIBBBLE (concept tells / where the conversation is going)

1. **Restaurant Dark-Mode Website — Jose Saamuel**
   https://dribbble.com/shots/23481907-Restaurant-Dark-mode-Website-Design
   - Exceptional: hero plates float on near-black with a single warm-amber pin-light; the negative space is doing the plating, not the photo.
   - Steal: stop trying to "light" the smoker hero. Drop one ember-temperature spot, let everything else fall to charcoal.
   - Shipped: 2024.

2. **Dark Restaurant Website tag — Dribbble curated stream**
   https://dribbble.com/tags/dark-restaurant-website
   - Recurring move across 2025 shots: oversized italic serif headline pinned to the LEFT rail, food shot pushed off the right edge (intentional bleed). Reads like a magazine cover, not a homepage.
   - Steal: pin "South Valley BBQ & Lounge" lockup left-rail vertical, let brisket photo bleed past the viewport edge on the right.

3. **Cocktail Lounge tag (17 shots) + Speakeasy Bar tag (14 shots)**
   https://dribbble.com/tags/cocktail_lounge | https://dribbble.com/tags/speakeasy_bar
   - Exceptional pattern: "menu as ledger" — drinks in a two-column accounting layout with leader-dot dot fills between name and price, evoking old bar tabs.
   - Steal: BBQ menu as a butcher's ledger — item name, dot-fill leader, weight/price. Old-school, anti-DTC, anti-grid.

4. **Whiskey Bar tag — Dribbble**
   https://dribbble.com/tags/whisky_bar
   - Recurring 2025 move: tiny all-caps tracking-loose nav (10-11px) floating in upper-corner against blown-up serif. Almost rude scale contrast.
   - Steal: ditch the polite 14px header nav. Push wordmark to display scale and shrink nav to a whisper.

5. **Supper Club tag — "Mayfair Supper Club Bellagio" by Andrew Nye**
   https://dribbble.com/tags/supper_club
   - Exceptional: room-tone burgundy + tarnished-brass, with showtime billed like a Playbill ("DOORS 7PM / FIRST SET 9PM / LAST CALL 1AM").
   - Steal: replace generic "Live Music Tonight" with the Playbill stack — DOORS / FIRST SET / SECOND SET / KITCHEN CLOSES. Time is the headline.

6. **Scrolling Menu tag (3 shots)**
   https://dribbble.com/tags/scrolling-menu
   - Exceptional: horizontal-scroll menu where each dish is its own page-width spread, not a card. Scroll-snaps like a deck.
   - Steal: turn the SV menu into a horizontal scroll-snap deck on desktop. Each section (Smoke / Sides / Bar / Late Night) is one full-bleed spread.

7. **Music Venue tag — Dribbble curated**
   https://dribbble.com/tags/music-venue
   - Recurring 2025 move: lineup as marquee scroll-ticker beneath the hero, NOT inside an event card. The lineup is wallpaper, not a widget.
   - Steal: persistent bottom-bar marquee with tonight's act + showtime, like a sportsbook ticker.

## CATEGORY 2 — BEHANCE (the *why* behind the choices)

1. **Bacàn — Pentagram (2024, Williamsburg)**
   https://www.pentagram.com/work/bacan/story | BP&O writeup: https://bpando.org/2024/06/27/italian-restaurant-branding-bacan-by-pentagram/
   - Rationale: "Bacàn" = the *sound* of a loud dinner party. The custom typeface (Grand Bacàn Sans) ships in THREE weights named for volume: loud → louder → loudest. Letterforms expand and collide as sound waves.
   - Steal for SV: weight-as-volume. A "Quiet / Live / Late" tri-state where typography literally gets heavier as the night progresses. Type *is* the timeline.

2. **Coqodaq — Pentagram / Emily Oberman (2024)**
   https://www.pentagram.com/work/coqodaq | https://thedieline.com/emily-oberman-and-pentagram-turn-fried-chicken-into-high-design-with-coqodaq/
   - Rationale: reverse-contrast typography (thin verticals, fat horizontals) flips fried-chicken vernacular into fine-dining register. The "O" carries a hidden Korean glyph.
   - Steal for SV: a reverse-contrast wordmark for "SOUTH VALLEY" — flat top/bottom, hairline sides. Reads as both BBQ-joint signage AND fine-dining cover. The bar across the top doubles as the smoker's horizon line.

3. **Smoky PIT Texas BBQ — Behance (Vietnam-based studio)**
   https://www.behance.net/search/projects/bbq
   - Rationale: monogram built from a top-down brisket cross-section (bark ring + smoke ring + meat). Functions as logo, as menu divider, as loading spinner.
   - Steal for SV: a "ring system" mark — concentric rings = bark / smoke / meat. Use as section dividers, page-load indicator, and pricing-tier icon. One mark, six jobs.

4. **Bleiker's Smokehouse Rebrand — Behance**
   https://www.behance.net/gallery/151553289/Bleikers-Smokehouse-Rebrand
   - Rationale: photography is shot on raw butcher paper backdrops. Every prop is paper-wrapped. The brand world is *one* material made into everything.
   - Steal for SV: commit to ONE substrate (kraft butcher paper) for every shot — menus, plates-from-above, hero, even the 404. Material consistency > color consistency.

5. **Mucca Design — F&B portfolio**
   https://www.behance.net/mucca | https://www.mucca.com
   - Rationale (across multiple NYC restaurant projects): historicist typography from period-correct sources, NOT generic serifs. They research the era and import letterforms with rationale.
   - Steal for SV: lock the headline face to a *specifically* Reconstruction-era American display cut (1870s-1880s wood type, e.g. HWT Mardell or similar). Tie it to the West Orange / Newark industrial heritage in the about page, not just used silently.

## CATEGORY 3 — MOBBIN (production primitives quietly winning)

1. **Resy iOS Restaurant detail flow**
   https://mobbin.com/explore/flows/84491685-d675-454f-9b2c-509c3905a4bd
   - Pattern: sticky time-picker pill that follows the user down the entire page. Reservation never out of reach.
   - Steal: persistent "Reserve · Tonight 7:30" pill in bottom-right corner from scroll-y > 200. Updates time-of-day live.

2. **OpenTable Web Restaurant Results & Discover flow**
   https://mobbin.com/explore/screens/96cafbda-9bed-4430-8295-9664d7f19b2d | https://mobbin.com/explore/flows/fd77e1ad-c0d9-48d8-8de5-0dad8b5a531e
   - Pattern: chip-row time filter ("6:00 / 6:30 / 7:00 / 7:30") inline with the hero, not buried in a modal. Decision happens in the hero.
   - Steal: chip row of tonight's available 15-minute slots directly under the hero photo. One tap = reservation flow open with that slot prefilled.

3. **Eventbrite Web Concert Event Listings**
   https://mobbin.com/explore/screens/0ff57c0a-93fd-4075-acb2-7893592e5d35
   - Pattern: event row uses a TWO-LINE date stack (big day-number / tiny month-DOW) on the left rail, headline on the right. Reads at a glance.
   - Steal: lineup list with calendar-tear date blocks. Day number is the biggest type on the page after the headline.

4. **Luma Web — scanning a ticket flow**
   https://mobbin.com/explore/flows/677c310b-74ca-4a11-a9b6-eeb0bc90d6f4
   - Pattern: Luma's confirmation screens use enormous serif headlines for *event names only*, sans for everything else. The event name is treated like a book title, not a label.
   - Steal: act names in the lineup get the same serif-headline treatment as menu items. Treat the band like a dish.

5. **Mobbin Web Gallery patterns (270+ refs)**
   https://mobbin.com/explore/web/ui-elements/gallery
   - Pattern across 2025 entries: lightbox-on-scroll — gallery doesn't open a modal, it *expands inline* and pushes everything down. No state change, no overlay scrim.
   - Steal: smoke-pit photo gallery expands inline on click — feels like flipping a contact sheet, not opening a modal.

6. **Web Event Detail screen index (180+ refs)**
   https://mobbin.com/explore/web/screens/event-detail
   - Recurring pattern: "Doors / Show / End" three-cell horizontal time strip directly under the event title. No prose, just three timestamps.
   - Steal: replace narrative copy under each lineup entry with a three-cell strip: DOORS · DOWNBEAT · LAST CALL.

## CROSS-SOURCE SIGNAL — patterns appearing in all three channels

1. **Time-as-typography.** Dribbble (supper-club Playbill stack), Behance (Bacàn's weight-as-volume), Mobbin (Doors/Show three-cell). Time isn't metadata in 2026 — it's a typographic element with its own scale.

2. **Reverse-contrast / extreme-contrast display type.** Dribbble whiskey-bar shots, Coqodaq's reverse-contrast wordmark, Luma's serif-event-name-only. The hierarchy is binary: one giant thing, then a whisper. No mid-weights.

3. **Inline expansion over modal overlays.** Mobbin gallery and event-detail patterns, plus 2025 Dribbble shots showing scroll-snap menu decks. The modal is being retired. Content moves the page; it doesn't float on top.

4. **One-material brand worlds.** Behance Bleiker's (butcher paper everywhere), Mucca's period-source rigor, Dribbble's grain-paper restaurant menus. Pick a substrate and let it be the whole grammar.

5. **Ledger / billing-document layouts.** Cocktail-lounge dot-leader menus on Dribbble, OpenTable chip rows on Mobbin, Bacàn's signage-as-document feel. Restaurants are returning to *administrative* visual languages: tabs, ledgers, manifests, playbills.

6. **Lineup-as-marquee, not lineup-as-card.** Dribbble music-venue shots and Mobbin event-detail screens both ditch the card grid for horizontal ticker / scroll-snap formats.

## PATTERNS TO INJECT INTO SOUTH VALLEY v2

(none of these are already on the visual-research punch list)

1. **Tri-weight "Volume" type system.** Three weights of the display face named Quiet (lunch), Live (showtime), Late (after-midnight). Time of day on the server determines the active weight. Inspired by Bacàn.

2. **Reverse-contrast wordmark.** Custom "SOUTH VALLEY" lockup with hairline vertical strokes and slab horizontals. Top horizontal doubles as smoker-horizon line in the hero. Inspired by Coqodaq.

3. **Concentric ring system mark.** Single mark = bark / smoke / meat rings. Reused as section divider, scroll progress indicator, pricing-tier glyph, favicon. One asset, six jobs. Inspired by Smoky PIT.

4. **Butcher-paper substrate commitment.** All photography re-shot or treated to read as if on kraft. Menus, 404 page, email receipts all share the paper. Material before color. Inspired by Bleiker's.

5. **Ledger menu with dot-leader rails.** BBQ menu rendered as an old bar-tab ledger: name · · · · · · weight · price. Anti-DTC, era-correct. Inspired by Dribbble cocktail-lounge cluster.

6. **Doors / Downbeat / Last Call three-cell strip.** Replace narrative event copy with three timestamps in a row, ledger style. Lifted directly from Mobbin event-detail consensus.

7. **Persistent reservation pill with live time-of-day.** Bottom-right pill that re-renders every minute: "Reserve · 7:42 PM tonight." Inspired by Resy + OpenTable chip patterns.

8. **Horizontal scroll-snap menu deck.** Each menu section is one viewport-wide spread, scroll-snapped. Replaces the long vertical menu. Inspired by Dribbble scrolling-menu tag.

9. **Lineup as bottom marquee ticker.** Persistent bottom-edge marquee with tonight's act + downbeat time, scrolling slow. Wallpaper, not widget. Inspired by music-venue tag + Eventbrite patterns.

10. **Calendar-tear date blocks for the lineup index.** Day-number is the second-largest type on the page, day-of-week + month a whisper above it. Inspired by Eventbrite + Luma patterns on Mobbin.
